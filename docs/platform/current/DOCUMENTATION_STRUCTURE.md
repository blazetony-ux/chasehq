# Documentation structure

The v0.62.0 pickup documentation refresh separates game knowledge from tool knowledge.

- Chase H.Q.-specific conclusions moved under `docs/chasehq/`.
- Research Workbench/API architecture and release/build records moved under `docs/platform/`.
- Generic reverse-engineering methods live under `docs/methods/`.
- Historical files are retained rather than deleted so evidence provenance is preserved.

This is a documentation-only restructuring; it does not claim new emulator/game behaviour.
