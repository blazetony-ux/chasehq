# Research Workbench / platform documentation

This tree documents the **tool**, not Chase H.Q. game behaviour.

- `current/` — current architecture and operating documentation for the Workbench, API, evidence/provenance systems and research-session launcher.
- `history/` — release notes, build-validation records, historical CLI references and implementation-era notes.

Game-specific addresses, conclusions and hypotheses belong under `docs/chasehq/`. Reusable reverse-engineering procedures belong under `docs/methods/`.
