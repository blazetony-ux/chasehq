Welcome to ChaseHQ-Native

What the project is, how the runtime and Workbench fit together, and where to begin.

Current release

v0.66.9.3 is the current promoted release; direct Windows qualification provenance is 0.66.9.3-RC5 SHA-256 19b7ed48edae98fd99f660ef56a949573050cabc2958fcdba2833a7888103961.

ChaseHQ-Native is both a native Chase H.Q. runtime and an evidence-driven reverse-engineering platform. The SDL window is the live game/render output; the Research Workbench is the browser-based control, inspection, scripting and documentation environment.

Core rule

Gameplay and rendering fidelity are the project. Tooling exists to make behaviour observable, reproducible and provable.

  • Use checkpoints or scenarios to start from known states.
  • Prefer API/scriptable experiments over one-off UI gestures.
  • Capture evidence with build, frame, checkpoint and source metadata.
  • Promote only sufficiently proven findings into authoritative knowledge.

Forensic Timeline: record once, investigate repeatedly

Capture a gameplay event once, then import/seek/inspect it through the normal research APIs and fork historical frames back to live execution.

Forensic Timeline v1 stores a deterministic CHQSTATE for every recorded frame and an unfiltered bus-write provenance stream. This intentionally prioritises fidelity and later analysis over storage efficiency.

api timeline.record.start name=turbo-complete-cycle

api timeline.record.stop

After timeline.load/timeline.seek, the ordinary memory, register, gameplay, sprite and palette inspection APIs operate on the selected historical checkpoint. timeline.fork-live keeps that checkpoint loaded and returns to paused live execution.

Semantic discipline

The proven 0x10A080-0x10A0BF record may be called CONFIRMED_TARGET_CAR only in explicit Stage-1 checkpoint context; otherwise it remains UNCLASSIFIED_TARGET_RECORD. Raw visible sprites remain UNCLASSIFIED_DYNAMIC_OBJECT; temporal tracks remain UNCLASSIFIED_OBJECT_CANDIDATE. Stable surface candidates use conservative course-record signatures while volatile TC0150 render words remain separate raw evidence. Do not call candidates AI cars, obstacles, asphalt or dirt until separate evidence supports those meanings.

  • Road left/centre/right geometry and the player driven line are separate outputs.
  • Raw player lateral position/error remains authoritative; the SVG player line is a projection for map visualisation.
