ChaseHQ-Native 0.67.0.0-RC6.3.33 ROM sprite-map atlas
Directly decoded from the locally supplied Chase H.Q. spritemap and OBJ graphics ROM regions; no live sprite-RAM occurrence is required.
Formats are explicit interpretations: OBJ-A 128x128 (8x8 chunks), OBJ-B64 64x128 (4x8), OBJ-B32 32x128 (2x8). Raw-pen PNGs are palette-independent; palN PNGs use the current runtime TC0110PCR palette bank only as a viewing aid.
Semantic identity is not inferred from ROM appearance alone; correlate with runtime evidence before promotion.
